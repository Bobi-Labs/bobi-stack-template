bobi-stack · how the work is organised

One keeper, many boxes

Each chat has one job. You talk to the one that holds the context.

A box owns one job: a project, or one kind of work. It has a folder and a log, so it outlives any chat.

The keeper sits above the boxes: it remembers cross-project decisions, passes messages, and settles disagreements.

A sub-keeper is optional: only when one area runs several chats at once. Start without one.

One box brings you each decision, never two.
