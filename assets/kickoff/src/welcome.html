bobi-stack · welcome

Welcome to bobi-stack

A head start on a real app, and a way of working with Claude that keeps long projects on track.

1

What it is

A ready-made web project, with the database, sign-in and screens already wired, plus a briefing, memory and checklists for Claude.

2

How it helps your work

Claude picks up where you left off, pushes back when something's a bad idea, and checks its own work before it says "done".

3

How the work is organised

Each project gets its own chat, a box. Running several? One keeper sits above them and keeps them in step, so you're never the messenger.

You → keeper → box · box · box

4

What happens now

A short setup: check your machine, pick a path, set up the project. About 20 to 40 minutes. You answer, Claude does the rest.

5

Questions?

Your FAQ comes with this setup: boxes, keepers, sub-keepers, and when you need each. Ask Claude anything, any time.
