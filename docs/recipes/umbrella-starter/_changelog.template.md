# Umbrella changelog: high-impact decisions

> **Template file.** Save as `docs/umbrella/_changelog.md` in the keeper repo, delete this blockquote.

Dated entries for decisions that affect multiple repos under the umbrella. Curated by the keeper's Claude; promoted from per-project logs when entries prove durable.

Read protocol: every Claude session reads the last ~10 entries here at session start.

Format:

```markdown
## YYYY-MM-DD — short title — `[scope]`

One-paragraph summary of the decision. Reference the per-project log entry
that surfaced it (if applicable) and the strategy-doc commit that promoted it.
```

Scope tags: `[infra]`, `[architecture]`, `[brand]`, `[content]`, `[process]`, `[security]`, `[product]`.
