Let Claude
set you up.

Someone at Bobi Labs sent you this page. It gets you working on bobi-stack: a project scaffold, plus a way of working with Claude that keeps long projects on track. Claude does almost all of it. You answer a few questions.

1

Get Claude Code

Install the Claude desktop app and open its Code tab, or use Claude Code in VS Code or a terminal if you already have it. It needs a paid Claude plan.

Open it in your home folder (or any folder; it will ask where your project should go).

2

Paste this, and press enter

It points Claude at one fixed, reviewed version of the setup, so you can see exactly what it will follow.

Set me up with bobi-stack. If git isn't installed, help me install it first. Then, in my home directory, clone https://github.com/Bobi-Labs/bobi-stack-template.git into a folder named bobi-stack-kickoff (if that folder already exists, use it instead), fetch, and check out commit ddc2a9e567884d8765034a9b8125b501af09cc9c. Read KICKOFF.md in that folder and walk me through it.
3

Answer its questions

Claude will:

  • check your machine and offer to install what is missing (it asks first);
  • ask whether you are joining someone's project, bringing your own, or starting something new;
  • set the project up, and explain in plain terms how it organises work across chats;
  • run a quick pre-mortem with you: imagine it failed, and ask why, before you build;
  • leave you with a working project and the exact words to pick up next time.

What you do yourself

Approve installs, and sign in to GitHub (and, if your project needs them, Supabase or Vercel) in your browser. Never paste a password or key into the chat; Claude will tell you where those go.

If you stop halfway

Open Claude again and paste the same prompt. It picks up where you left off.
